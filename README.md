### CS340 Reflection

I write programs that are maintainable, readable, and adaptable by planning for how the software will be used and ensuring that it meets all of the project requirements. I also use meaningful comments and clear code organization to make the program easier for others to understand. Well-documented code makes it much easier to locate specific sections that need to be updated, modified, or debugged in the future. To make my programs adaptable, I follow current programming best practices and create reusable functions that can be modified or extended as requirements change.

The CRUD operations I developed in this project can be applied to many other database-driven applications that require users to create, read, update, and delete records. These operations are fundamental to a wide variety of software systems, making them valuable skills that I can use in future projects involving databases and data management.

When approaching a programming problem, I break it down into smaller, more manageable pieces instead of trying to solve the entire problem at once. This is the same approach I used for the Grazioso Salvare project. I implemented the Create function first, followed by the Read, Update, and Delete functions. After completing each function, I tested it thoroughly before moving on to the next one. I also retested the previously completed functions to ensure that new changes did not introduce any issues. This incremental approach made debugging easier and helped ensure that the application remained reliable throughout development.

A project like this provides significant value to a company such as Grazioso Salvare by improving the efficiency of locating dogs that meet specific training requirements. Instead of manually searching through thousands of records, users can filter the database based on the type of disaster response they are preparing for and quickly narrow the results to a small list of qualified dogs. This saves time, improves productivity, and allows the organization to focus on training the most suitable animals for each mission.
